# Project instructions

This project is arhandtrackiig_game.

## Web design

For requests to build or improve website UI, read `.agent/skills/frontend-design/SKILL.md` and follow its design workflow. Its source is https://github.com/anthropics/skills/tree/main/skills/frontend-design (Apache-2.0); the accompanying license is preserved in the skill folder.

Use the existing HTML, CSS, and JavaScript stack unless the user requests a change. Preserve game logic, camera permissions, and hand tracking while improving presentation. Make Thai text readable, support mobile layouts, visible keyboard focus, and reduced motion. Verify the affected pages after edits.
